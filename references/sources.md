# Sources

The rules in this skill come from the following sources. When adding new rules, please add the source here.

- Kristen M. Naegle. *Ten simple rules for effective presentation slides.* PLoS Comput Biol 17(12): e1009554, 2021. https://doi.org/10.1371/journal.pcbi.1009554
  → S1, S2, S3, S5, S6, S7, S8, S10, S11, F2, F8, V1–V4, V8, D2, D4; ~1 min per slide.
- Berthold Herrendorf. *How to Make Academic Presentations*, 2019. https://roozbeh-hosseini.github.io/PresentationTipsLong.pdf
  → Difference between slides and papers, nested layers, newspaper-style argument, opening, placement of literature review, S4, S9, F1, F4, F7, V1, V7, D5, 2–3 min per slide (long talks), do not run overtime.
- MIT NSE Communication Lab. *Structuring a Slide Presentation.* https://mitcommlab.mit.edu/nse/commkit/structuring-a-slide-presentation/
  → Purpose / audience / core message, hourglass structure, planning backward from results, 2–4 groups of points, title-checklist workflow, ending returns to the big question, plan by time rather than slide count.
- San José State University Writing Center. *Presentation Writing*, 2025. https://www.sjsu.edu/writingcenter/docs/handouts/Presentation%20Writing.pdf
  → Goals / audience / content, division of labor between script and on-screen text, ≥ 24 pt, compressing long sentences into signposts (slide-design.md Example 3).
- Further reading cited by the above sources: Bourne, *Ten Simple Rules for Making Good Oral Presentations* (2007); Lortie, *Ten simple rules for short and swift presentations* (2017); Kosslyn et al., *PowerPoint presentation flaws and failures* (2012); Doumont, *Trees, Maps, and Theorems* (2009).
